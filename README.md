# CodeAlpha_BasicChatbot

## Basic Chatbot

A simple rule-based chatbot developed using Python as part of the CodeAlpha Internship Task 2.

## Goal
Build a simple rule-based chatbot that interacts with the user using predefined responses.

## Scope
- Takes user inputs like "hello", "how are you", and "bye".
- Provides predefined replies such as "Hi!", "I'm fine, thanks!", and "Goodbye!".

## Key Concepts Used
- if-elif statements
- Functions
- Loops
- Input/Output

## How It Works
The chatbot takes input from the user and checks it against predefined conditions. Based on the user's input, it provides an appropriate response.

## Technologies Used
- Python
